# 04-Guías — Índice

## Propósito

Esta sección contiene guías operativas y de desarrollo para trabajar con HannaeX de forma consistente.

Las guías deben explicar cómo hacer algo, mientras que la arquitectura define cómo está organizado el sistema y las features describen qué capacidades existen.

## Diferencia entre secciones

```text
02-Arquitectura = cómo está diseñado el sistema
03-Features     = qué puede hacer el sistema
04-Guías        = cómo trabajar con el sistema
05-Planes       = qué se hará después
06-Registro     = qué ocurrió o cambió
```
